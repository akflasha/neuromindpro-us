HOW TO USE FOR A NEW PRODUCT

1. Keep the HTML file and images folder together.
2. Replace the images inside /images.
3. Keep EVERY filename exactly the same.
4. You do NOT need to edit image URLs in the HTML.
5. Replace the {{PLACEHOLDER}} content in the HTML for the new product.
6. Set {{CANONICAL_URL}} to the final page/domain.
7. Set {{ORDER_URL}} to the exact checkout/affiliate link.
8. Keep the visible rating and AggregateRating schema consistent.
